What has to work

Customers follow the path they receive. For D/E, that means solving user access, enrollment, learning, and completion as one provisioning problem. If any link fails, the customer is left without the training path we promised.

1 · AccessClient creates the users. Test existing groups before proposing a new access group.
2 · EnrollmentRules assign the right go-live learning, or the client uses a clear manual path.
3 · LearningThe course path replaces the trainer for D/E; task help supports real work.
4 · OwnershipClient monitors completion. PMs consult. Product Education does not provision users.

What a customer experiences

A staged learning journey, tied to real work.

Send the first tasks before launch, practice in go-live week, then add follow-on learning when the work becomes relevant.

What to expect: Staff receive role-based Academy learning in small waves. Each go-live mission pairs learning with a task to practice and a way to get help. The Academy admin tracks completion; a supervisor checks the first real task.

Each mission has a job outcome

For example: process an application, complete a move-in, or update a work order. The learner follows a short course sequence, uses a task checklist, and finds the matching Help Center guidance.

Critical start dependency · owner not set

Contract processing unlocks the live CA environment.

The biggest timing hurdle is the gap between contract signature and contract processing. Processing opens the live customer environment; the client can start configuring only after an initial admin user has been created. Consulting typically creates that admin during its first engagement after project kickoff.

Full courses and microcourses

Use a full course for a major workflow or setup decision that needs context and practice. Use a microcourse for one skill that benefits from a short lesson and practice.

Help Center how-tos

Give steps for a defined task or setting, including prerequisites, completion checks, and edge cases.

Overviews and release notes

Overviews orient people and route them to details. Release notes explain what changed and who needs to know.

Webinars: choose one home

Decide whether each webinar belongs in the LMS for assigned learning or the Help Center for reference. Don’t keep the same webinar in both.
